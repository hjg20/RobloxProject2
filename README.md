## Game
This project is now a playable prototype called **Casino Crawl**: a roguelite run where players start with a small in-game bankroll, gamble through scratch-offs/blackjack/loot boxes/high-roller tables, buy combat power, clear enemy rooms, defeat the boss, and earn permanent upgrade tokens.

The loop is:

1. Start a run.
2. Gamble with run-only cash.
3. Buy shop upgrades such as sword damage, medkits, armor, and luck charms.
4. Start the next fight and defeat the room.
5. Beat the boss, bank permanent tokens, then buy meta upgrades.

All gambling uses fictional run cash only. No Robux or real-money wagering is implemented.

Tuning lives in `src/shared/GameConfig.luau`. The server-authoritative game loop lives in `src/server/init.server.luau`, and the HUD/buttons live in `src/client/init.client.luau`.

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "RobloxProject2.rbxlx"
```

Next, open `RobloxProject2.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
